BEFORE YOU START

課前準備清單

  • 可使用 ChatGPT 的 OpenAI 帳號（方案與額度以授課當天畫面為準），並先從 ChatGPT 官方下載頁安裝應用程式
  • 了解 Chat、Work、Codex 之間的差異，並能依任務選擇適合的工作模式
  • 筆電可安裝軟體、網路正常，並準備一個不含個資的練習資料夾
  • 先開啟 Padlet 課程入口，取得已確認的操作筆記、素材與延伸範例
  • Part 3 先確認 Computer Use 已啟用，依提示授權，Chrome 操作則連接瀏覽器擴充功能
  • Codex、Gemini Notebook 與 Netlify 是進階示範；需要跟做時再登入自己的帳號並確認權限
  • 正式操作前先備份原始檔；寄送、發布、刪除與覆寫前保留人工確認
