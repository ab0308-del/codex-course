與 AI Agent 一起工作

使用想法、流程規範與安全提醒

新北市大豐國小　·　許凱琳老師

MINDSET

交代清楚，它就會幫你把工作做完整

🤝 把它當成新同事

能力很強，但不知道你的習慣。背景、目標、限制說得越清楚，成果越接近你要的。

🧑‍🏫 老師仍是負責人

Agent 負責執行，老師負責判斷與驗收；送出、發布、刪除都由人決定。

交辦公式：背景＋目標＋資料＋限制＋交付格式＋驗收標準。

MY PROMPTS

我最常對 Agent 說的五句話

  1. 1
    「先告訴我你要怎麼做，我確認後你才開始動工。」
  2. 2
    「完成的時候，也教我怎麼做，因為我想了解這些步驟。」
  3. 3
    「先保留原始檔，另外做一份新版讓我看。」
  4. 4
    「我已經試過這個流程了，請幫我整理成可以重複使用的 Skill。」
  5. 5
    「請把目前做到哪裡、重要檔案和下一步寫成交接紀錄，方便下次接著做。」
經常使用之後，你就會知道每種任務該給什麼權限、該開啟哪個專案資料夾。

WORKFLOW

流程規範：每一次都走同樣四步

  1. 1
    先盤點：開啟正確的專案資料夾，讓它讀取現況、說明風險，不修改。
  2. 2
    再計畫：列出步驟、交付成果與驗收方法，等你確認。
  3. 3
    小範圍試做：先處理 3 筆或建立副本，再完整執行。
  4. 4
    實際驗收：打開成果、抽查內容、核對數量，不只看「已完成」。

⚠️ SECURITY

安全性：五件一定要守住的事

權限最小：只開啟需要的資料夾與應用程式，不開放整個「文件」或「桌面」。
Token 不公開：Token、API Key、密碼等同鑰匙，不投影、不貼對話、不放進檔案或 GitHub。
個資不外流：練習用合成資料；學生姓名、成績、照片不上傳到不必要的服務。
關鍵動作人工確認：登入、付款、寄送、發布、刪除、覆蓋前一定先停下來。
先備份再動手：重要檔案先複製一份，讓 Agent 在副本上工作。

課後加練

三種任務，回去接著練

  1. 1
    口述資料填入 Word 表單：缺少的資訊先標待補。
  2. 2
    整理公務資料夾：先列建議，只在副本上整理。
  3. 3
    依公開試題分析命題方向：重新設計可列印評量卷。
完整步驟與提示詞請見 已確認的學員操作筆記。
