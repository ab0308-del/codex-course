ChatGPT AI Agent Part 5

結語
與 AI Agent 一起工作

使用想法、流程規範與安全提醒

新北市大豐國小　·　許凱琳老師

MINDSET

交代清楚，它就會幫你把工作做完整

🤝 把它當成新同事

能力很強，但不知道你的習慣。背景、目標、限制說得越清楚，成果越接近你要的。

🧑‍🏫 老師仍是負責人

Agent 負責執行，老師負責判斷與驗收；送出、發布、刪除都由人決定。

交辦公式：背景＋目標＋資料＋限制＋交付格式＋驗收標準。

MY PROMPTS

我最常對 Agent 說的三句話

  1. 1
    「請你幫我完成的時候，教我怎麼做好這件事，因為我也想了解這個步驟。」
    例：GitHub 發布網站、LINE 小幫手
  2. 2
    「先告訴我你要怎麼做，我確認後你才開始動工。」
  3. 3
    「這樣的工作流程很棒，幫我做成一個 Skill。」
經常使用之後，你就會知道每種任務該給什麼權限、該開啟哪個專案資料夾。

WORKFLOW

流程規範：每一次都走同樣四步

  1. 1
    先盤點：開啟正確的專案資料夾，讓它讀取現況、說明風險，不修改。
  2. 2
    再計畫：列出步驟、交付成果與驗收方法，等你確認。
  3. 3
    小範圍試做：先處理 3 筆或建立副本，再完整執行。
  4. 4
    實際驗收：打開成果、抽查內容、核對數量，不只看「已完成」。

⚠️ SECURITY

安全性：五件一定要守住的事

權限最小：只開啟需要的資料夾與應用程式，不開放整個「文件」或「桌面」。
Token 不公開：Token、API Key、密碼等同鑰匙，不投影、不貼對話、不放進檔案或 GitHub。
個資不外流：練習用合成資料；學生姓名、成績、照片不上傳到不必要的服務。
關鍵動作人工確認：登入、付款、寄送、發布、刪除、覆蓋前一定先停下來。
先備份再動手：重要檔案先複製一份，讓 Agent 在副本上工作。

TIPS

實際使用的三個提醒

跨電腦、儲存空間、記憶體

TIP 1 · 跨電腦

安裝雲端硬碟桌面版，學校和家裡都能接著做

  1. 1
    安裝 Google 雲端硬碟桌面版，把專案資料夾放在雲端硬碟中。
  2. 2
    兩台電腦都開啟同一個資料夾，就能延續同一個專案。
  3. 3
    代價：檔案需要同步，電腦效能會變慢；大量檔案時更明顯。
避免兩台電腦同時修改同一個專案，等同步完成再換另一台。

TIP 2 · 儲存空間

練習刪除不要的檔案

📈 檔案會一直增加

每次試做、副本、截圖、暫存檔都會留下來，累積起來造成儲存空間壓力。

🧹 定期整理

請 Agent 列出「可刪除候選清單」放進「待刪除」資料夾，由你確認後再刪。

請盤點這個專案資料夾，列出暫存檔、重複檔與舊版本，說明每個檔案能不能刪除。先移到「待刪除」資料夾，不要直接刪除。

TIP 3 · 記憶體

不要貪心一次開太多 Agent

  1. 1
    同時開一個、兩個、三個、四個任務……視窗關掉後它仍會繼續工作。
  2. 2
    每個任務都會消耗記憶體，太多就可能過載當機。
  3. 3
    按 Ctrl＋Shift＋Esc 開啟工作管理員，查看記憶體使用量。
記憶體使用率長時間超過 80%，就先等手上的任務完成，再開新的。
