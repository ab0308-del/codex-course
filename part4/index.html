跨 Agent Handoff
Codex ↔ AntiGravity

讓兩個 AI 接力完成同一件事

新北市大豐國小　·　許凱琳老師

為什麼要交接

額度用完換手、
或讓不同強項的 Agent分工

這就是 AI Agent 時代的協作方式

HOW IT WORKS

交接的原理

  • 1
    同一個專案資料夾：兩個 Agent 共用同一份工作區。
  • 2
    共用藍圖：agents.md（Codex）／CLAUDE.md（Claude Code）。
  • 3
    交接檔 handoff.md：記錄做到哪、待辦、注意事項。
  • 4
    注意：不要兩個同時寫同一檔案，輪流接力。

HANDS-ON

練習交接

寫交接檔 → 換手接力

STEP A — 交棒

請 Codex 寫交接檔

  1. 1
    Codex 做到一半（或快沒額度）時，對它說：幫我寫一個交接檔 handoff.md， 寫清楚目前做到哪、待辦、注意事項， 等一下換 AntiGravity 接手。
  2. 2
    它會把進度寫進 handoff.md 與 agents.md。

STEP B — 接棒

換 AntiGravity 接手

  1. 1
    開 AntiGravity，Add Folder 選同一個資料夾。
  2. 2
    對它說：上一個 Agent 已留下交接檔， 請讀 handoff.md 與 agents.md，接著往下做。
  3. 3
    它讀完就知道進度，接力完成。反過來也行（AntiGravity → Codex）。

📄 聲音克隆 Handoff

家用電腦寫好 HANDOFF_聲音克隆_給AntiGravity.md，放進雲端同步的 vault。

🏫 到學校接手

學校電腦的 AntiGravity 讀它 → 從 Step 0 clone repo 開始往下裝。

同一份交接檔，跨電腦、跨 Agent 都能接力——這就是 Handoff 的威力。
