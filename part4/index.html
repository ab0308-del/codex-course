CONNECT

讓 Agent 連上外部工具的幾種方式

🧩 外掛程式／Connector

官方做好的連接，登入授權後就能使用，例如 Google、GitHub、Notion、Canva。

🔌 MCP

AI 與外部工具的「標準插頭」；自己加入伺服器，連接更多服務。

🧭 Skill

教 AI 一套可重複使用的 SOP。

⏰ Automation

在指定時間重複執行已穩定的流程。

本研習以 Codex 示範自訂 MCP；可用功能與設定入口以當天介面為準。

PLUGINS

外掛程式：先認識，有需要再開啟

🐙 GitHub

讀取與管理程式專案、建立網頁版本紀錄，搭配 GitHub Pages 發布網站。

📓 Notion

搜尋與整理 Notion 頁面、資料庫，把成果寫回筆記。

🟢 Google 家族

Gmail、Google 雲端硬碟、日曆、文件、試算表：讀信、找檔、排行程。

🎨 Canva

搜尋與建立 Canva 設計，把內容套進範本做成海報或簡報。

開啟方式：設定 → 應用程式（連接器）→ 選擇服務 → 登入授權。只開需要的，用不到就取消授權。

⚠️ SECURITY

Token 與 API Key 等同密碼，絕對不要公開

不投影、不截圖：產生 Token 的畫面不要出現在簡報、錄影或直播。
不貼進對話：不要把 Token 直接貼給 AI；用安裝精靈或官方授權流程輸入。
不放進檔案：不寫進簡報、筆記、AGENTS.md、handoff.md，也不上傳到 GitHub。
外洩就作廢：懷疑外洩時，立刻到該服務的設定頁刪除舊 Token、重新產生。
能用官方 OAuth 授權（跳出瀏覽器登入）的，就不要用 Personal Access Token。

MCP 1

Padlet MCP：打造 AI 研習助教

建立互動牆、整理回應、草擬個別回饋

Padlet MCP

Padlet｜先確認連接的帳號

先從應用程式或外掛程式連接 Padlet。

若講師採用自訂 MCP，依專案最新說明安裝。

請確認目前連接的 Padlet 帳號，只讀取，不要建立或修改任何內容。

講師提供的 Padlet MCP 專案

PADLET · TASK ①

一句話建立研習互動牆

  1. 1
    指定對象、主題、區段與每區引導問題。
  2. 2
    要求 Codex 先在對話中預覽版面結構，確認後才建立。
  3. 3
    建立後回到 Padlet，手動檢查分享權限，並視需要開啟留言與 reactions。
請規劃一面「AI Agent 教師研習」Padlet，分成： 課前期待、今天學到什麼、可以應用在哪裡、仍然想問的問題。 每區放 2 個簡短引導問題。先預覽內容，等我確認後再建立。

PADLET · TASK ②

讀取全班回應，先摘要、不回寫

📊 分類統整

將回應整理為「已理解、想應用、仍有疑問」，統計數量與常見觀點。

🔎 保留例外

不確定、離題、可能涉及個資的內容另外列出，不替學員猜測。

提示詞：「先在對話中提供摘要，不要直接貼回 Padlet。」讀取與外部寫入是兩個不同授權階段。

PADLET · TASK ③

個別回饋：預覽、確認、再留言

  1. 1
    請 Codex 為每則回應草擬一句具體、友善、能引導思考的回饋。
  2. 2
    講師逐則檢查語氣、正確性與是否洩漏個資。
  3. 3
    只把確認過的回饋留言到對應貼文；無法配對就停止詢問。
  4. 4
    可延伸：答對加 ❤️、迷思用蘇格拉底式問題回應，但先確認 Padlet 已開啟互動。
  5. 5
    最後產出研習摘要：主要收穫、待解問題、後續行動與人工處理清單。

MCP 2

Gemini Notebook MCP

讓 Agent 幫你建立筆記本、加入來源、產生語音摘要

Gemini Notebook MCP

Gemini Notebook｜先讀教材的 MD

教材原檔：01-連接-NotebookLM.md。

原文寫給 Claude Code／opencode，請 Codex 先閱讀、檢查環境，再按目前方式調整。

先看安裝計畫，確認後才執行。不要直接建立或刪除測試筆記本。

提示詞

Gemini Notebook｜請 AI 協助連接

請先閱讀我附上的「01-連接-NotebookLM.md」，協助我在目前的 Codex 連接 Gemini Notebook MCP。 1. 先檢查我的作業系統、需要的工具，以及是否已經安裝或連接過，告訴我打算怎麼做，等我確認再安裝。 2. 這份檔案原本寫給 Claude Code／opencode，請依目前 Codex 的安裝方式調整，並查閱工具專案的最新說明，不要照抄不適用的指令。 3. 需要 Google 登入時，請停下來讓我自己操作，不要顯示或複製我的登入憑證。 4. 完成後只列出我的筆記本，確認 MCP 能讀取；不要建立或刪除測試筆記本，也不要修改其他 MCP 設定。 5. 如果失敗，先說明原因和修正方法，不要直接清除原有設定或登入資料。
完整步驟在操作筆記

講師參考

產品改名，工具指令仍保留舊名稱

uv tool install notebooklm-mcp-cli nlm login nlm setup add codex

登入由自己完成；完全重開應用程式後，只用 MCP 列出筆記本驗證。

套件名稱與執行檔仍保留 notebooklm，不要直接替換文字。

工具專案最新說明

Gemini Notebook 實作

延續 SEL 課程，整理來源與語音摘要

請用 Gemini Notebook MCP，協助我整理【SEL】課程的資源。 1. 先讀取「網路資源」文件，把打算加入的來源清單給我看，等我確認。 2. 我確認後，再建立「【四年級 SEL 課程】」筆記本，加入確認過的來源。 3. 請根據這些來源回答：「【四年級學生學習情緒覺察時，最需要理解的三件事是什麼？】」 4. 幫我產生一段適合學生聽的中文語音摘要，完成後告訴我在哪裡收聽；若無法產生，請說明原因。 不要修改或刪除其他筆記本。
到筆記本核對來源，再實際收聽語音。

MCP 3

Codex 小遊戲 × Netlify MCP

從一句需求開始，完成可玩、可驗收、可分享的網頁遊戲

NETLIFY

每位學員申請自己的 Netlify 帳號

  1. 1
    開啟 app.netlify.com，完成註冊與登入。
  2. 2
    確認能看到自己的 Team 與 Projects 畫面；後續網站都放在自己的帳號。
  3. 3
    Codex 也可能顯示其他部署選項；本堂課統一使用 Netlify MCP。

Netlify MCP

Netlify｜先確認帳號連接

請協助我連接 Netlify MCP。先確認目前是否已連接；如果需要設定，請依 Netlify 官方最新說明引導。 需要登入授權時讓我自己操作。完成後只確認帳號和網站清單，不要部署，也不要顯示 Token。

Netlify 官方連接說明

SECURITY

使用 MCP 授權；不公開 Access Token

Netlify 預覽

成語遊戲｜先給我預覽

請用 Netlify MCP，幫我把操作六完成的「【成語填空小遊戲】」建立預覽部署。 先確認要上傳的資料夾、檔案與 Netlify 帳號，讓我檢查。 我確認後才上傳，只建立預覽，先不要更新正式網站。 完成後給我預覽網址，實際開啟測試，並告訴我答題、計時、分數與重新開始是否正常。
預覽網址也可能被取得連結的人讀取，請使用練習資料。

Netlify 發布

預覽確認後，再正式上架

我已經確認預覽版可以正常使用。 請先提供幾個【成語遊戲】的 netlify.app 網站名稱供我選擇，說明是否可用。 等我選定後，再把剛剛確認過的版本正式部署，回報正式網址，並實際開啟檢查。

請自己用電腦與手機玩完一局，再確認正式發布。

UPDATE

網站上架不是結束：先修改，再重新部署

  1. 1
    一次只提出一組清楚修改，例如加入最高分、改成 45 秒或更換主題。
  2. 2
    在本機重玩、建立新預覽、開啟預覽網址驗收。
  3. 3
    確認新功能正常且舊功能沒壞，再更新正式網站。
固定節奏：修改 → 本機驗收 → 預覽部署 → 線上驗收 → 正式部署。

AGENT · SKILL

Skill：把重複又好用的動作封裝起來

適合做成 Skill

已經驗證過、之後會重複使用，而且有清楚輸入、步驟與驗收方式的流程。

本課範例

將「檢查網頁遊戲 → 建立 Netlify 預覽 → 回報驗收清單」做成重複流程。

先成功完成至少一次，才考慮做成 Skill；不要把尚未穩定的做法自動化。

AGENT · PROJECT RULES

AGENTS.md：寫給 Agent 的專案長期規則

  • 1
    記錄專案目標、重要檔案、命名方式與禁止事項。
  • 2
    記錄固定驗收：支援手機、不收集個資、部署前必須先建立預覽。
  • 3
    視為專案說明，而不是聊天記憶；換新任務時 Agent 仍可先讀取。
AGENTS.md 是有特定用途的 Markdown 檔；不是 Agent 寫的每一個 .md 檔都叫 AGENTS.md。

AGENT · HANDOFF

換 Agent 之前，先請它寫好交接內容

請把目前專案整理成 handoff.md，包含專案目標、已完成功能、重要檔案、已做過的測試、Netlify 部署狀態、尚未解決的問題與建議下一步。不要修改遊戲內容，不要寫入 Token 或密碼。

新 Agent 接手時：先讀 AGENTS.md 與 handoff.md，盤點現況，再提出接續計畫。

接上工具 🔌
