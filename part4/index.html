Work 自動化
與 Codex 工作接力

把一次成功，變成每次都能穩定完成

新北市大豐國小　·　許凱琳老師

REUSE

重複工作分兩條路：Work 排程，Codex 封裝專案規則

⏰ ChatGPT Work

讓已穩定的辦公流程執行一次、排程重複，或監控指定變化；重要動作仍需核准。

🧰 Codex

把本機專案 SOP 做成 Skill，並用 AGENTS.md 與 handoff.md 保存規則與進度。

兩條路都先完成一次、實際驗收，再考慮重複執行。

CODEX · SKILL

Codex Skill：把驗證過的 SOP 教給 Agent

  • 1
    先完成一次真實任務，記錄輸入資料、步驟、限制、交付成果與驗收規則。
  • 2
    用 skill-creator 封裝成自己的 Skill；重複任務不用每次重寫長提示詞。
  • 3
    換 3 組不同資料測試；若流程仍常出錯，先修 SOP，不急著自動化。

PROJECT MEMORY

AGENTS.md：專案長期工作規則

  1. 1
    AGENTS.md 是給 Agent 的專案說明，會隨工作區持續使用，不是聊天記憶。
  2. 2
    寫入專案目的、資料規則、禁止事項、檔名格式、驗收方式與常用操作。
  3. 3
    保持短而具體；只有在反覆遇到相同問題時，才新增一條長期規則。

CHATGPT WORK · AUTOMATE

Work 流程穩定後，再排程或監控

⏰ 適合自動化

固定時間、固定來源、固定格式，而且失敗容易察覺的流程。

🧑‍⚖️ 保留人工確認

寄送、發布、評分、刪除、覆寫、個資與對外承諾。

範例：「每週一整理 AI 教育新知成草稿，通知我檢查；不要自動寄出或公開發布。」

HANDOFF

跨帳號、跨 Agent 都能接著做

  1. 1
    AGENTS.md 保存長期規則；handoff.md 保存本次進度、決策、問題與下一步。
  2. 2
    切換帳號或 Agent 前，要求它更新交接檔並列出尚未驗收的成果。
  3. 3
    接手者開啟同一資料夾，先讀兩份文件、盤點現況，再提出接續計畫。
本機檔案可以延續，但對話歷史、記憶、額度、權限與外部服務登入不一定會轉移。
