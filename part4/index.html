與跨 Agent

讓 Codex 從會用變成超強

新北市大豐國小　·　許凱琳老師

$ SKILL

Skill 技能包：把 SOP 教給 AI

  • 1
    Skill＝給 AI 的技能包，遇到相關任務按需自動載入，不用每次寫一堆提示詞。
  • 2
    內建 Image Gen 圖像生成；用 skill-installer 安裝別人的技能（如動畫 remotion）。
  • 3
    用 skill-creator 把你的流程封裝成自己的技能（本質是一份 SKILL.md）。

MCP

MCP：AI 的萬能插頭

  1. 1
    MCP（Model Context Protocol）讓 AI 連接外部工具與資料來源、取得即時資訊。
  2. 2
    Context7：即時查最新技術文件，終端輸入 npx ctx7 setup 安裝。
  3. 3
    Notion 等：設定 → MCP 服務 → 新增伺服器 → 安裝後重啟 Codex。

AUTOMATE

自動化 + 一次完成多件事

⏰ 自動化排程

「每週一早上 10 點，連網搜尋 AI 新工具與模型，整理成報告。」

📦 一次多工

一個指令同時輸出 Documents（趨勢文件）＋ Spreadsheets（表格）＋ Presentations（簡報大綱）。

桌面寵物還能即時顯示工作進度，跑到哪一眼看到。

HANDOFF

跨 Agent 接力：Codex ↔ AntiGravity

  1. 1
    額度用完、或讓不同強項的 Agent 分工時，用交接檔接力。
  2. 2
    請 Codex：「寫一個 handoff.md，記錄進度與待辦，等 AntiGravity 接手。」
  3. 3
    開 AntiGravity，選同一個資料夾，說「讀 handoff.md 與 agents.md 接著做」。
真實範例：你做的「聲音克隆 handoff」就是這樣，跨電腦、跨 Agent 接力完成。
