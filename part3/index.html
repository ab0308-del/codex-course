DEMO 1

Computer Use

沒有外掛、沒有 API 的軟體，讓 AI 像人一樣點點看

CONCEPT

Computer Use：AI 看螢幕、動滑鼠、打字

✅ 適合用 Computer Use

需要「看畫面、點按鈕」的工作：Windows 工具（工作管理員）、一般網頁、只有桌面版的軟體。

↪️ 改用其他方式

已經有外掛或 MCP 能直接連的服務（Google、Notion、Padlet），用外掛更快、更準。

🐢 速度

它要「截圖 → 判斷 → 點擊」反覆進行，比直接處理檔案慢。

👀 全程可見

每一步都在螢幕上發生，老師可以邊看邊隨時喊停。

SETUP · SAFETY

開始前：安裝瀏覽器外掛，只開放需要的程式

  1. 1
    先安裝 ChatGPT 瀏覽器外掛（擴充功能），Computer Use 才能操作瀏覽器裡的網頁。
  2. 2
    在設定中只允許本次需要的 App，例如瀏覽器、工作管理員與檔案總管。
  3. 3
    先關掉 LINE、信箱、校務系統等含個資的視窗，AI 看得到螢幕上的一切。
  4. 4
    AI 操作時不要同時動滑鼠或鍵盤；登入、付款、寄送、刪除前一律停下來由人確認。

DEMO 1-1 — 提示詞

檢查電腦效能

電腦變慢了？讓 Computer Use 打開工作管理員幫你看，順便學會自己怎麼看。

請使用 Computer Use 幫我檢查這台電腦的效能： 1．開啟「工作管理員」（Ctrl＋Shift＋Esc），切到「效能」與「處理程序」。 2．回報目前 CPU、記憶體、磁碟的使用率。 3．找出最耗記憶體的前 5 個程式，用表格列出名稱與用量。 4．建議哪些可以關閉，並說明原因。 不要自己結束任何程式；做完後教我下次怎麼自己看。
連結 Part 5：同時開太多 Agent 任務會吃掉記憶體，這就是檢查的方法。

DEMO 1-2 — 提示詞

把選擇題做成 Google 表單測驗

延續 Part 2 任務 1：把紅毛城的 5 題選擇題，一題一題點進 Google 表單，做成可自動批改的測驗。

請使用 Computer Use 幫我建立 Google 表單測驗： 1．開啟練習資料夾中的「紅毛城 5 題選擇題」Word，讀取題目、選項與答案。 2．用瀏覽器開啟 Google 表單（使用已登入的帳號），新增空白表單，標題「淡水紅毛城行前小測驗」。 3．在設定中開啟「設為測驗」。 4．逐題建立選擇題，設定正確答案，每題 20 分。 5．完成後把表單的編輯網址給我。 不要輸入任何密碼；不要按「傳送」或分享給任何人，由我檢查後再發給學生。
這是 Computer Use 的強項：沒有現成外掛，但需要大量重複的點選與輸入。

DEMO 1 — 驗收

不只看它說完成：自己確認結果

📊 效能檢查

自己打開工作管理員，數字和它回報的差不多；它沒有擅自結束程式。

📝 表單測驗

自己用「預覽」作答一次：5 題都在、選項正確、交卷後分數正確。

🛡️ 過程

沒有開啟不相關的程式，沒有輸入密碼，沒有自行傳送或分享表單。

🧑‍🏫 學到方法

下次不靠 AI，自己也會看效能、會設定表單測驗。

DEMO 2

ChatGPT Work 示範

資料夾裡的檔案 → 可以直接交出去的辦公成果

DEMO 2 — 示範範例

研習回饋表 → 統計圖表 → 成果報告

示範內容以當天為準情境：研習結束後，把回饋表 Excel 整理成可以交給學校的成果報告。

請讀取資料夾中的「研習回饋表」Excel： 1．統計各題滿意度的平均與分布，畫成長條圖。 2．把開放式意見分成「收穫」「建議」「疑問」三類，各列出代表性意見。 3．整理成一份 A4 兩頁的 Word 成果報告，含圖表與結論。 先告訴我你的整理方式，確認後再產出；意見原文不要改寫成沒說過的內容。
觀察重點：Work 怎麼盤點資料、先提計畫，以及產出後如何對照原始數據驗收。

DEMO 3

Codex 示範

一段清楚的需求 → 一個可以玩的網頁遊戲

DEMO 3 — 示範範例

成語填空小遊戲

示範內容以當天為準先開一個獨立的專案資料夾，再交給 Codex。

請在這個資料夾製作一個成語填空網頁遊戲： 1．開始有啟動畫面，顯示遊戲說明。 2．每次隨機抽 10 個四字成語，隨機隱藏其中一個字，從 4 個候選字中選出正確答案。 3．每題有倒數計時，用時間血條顯示；答題進度用另一條血條顯示，兩者要區分清楚。 4．答對顯示慶祝動畫並自動進入下一題；答錯彈出正確答案，短暫停留後自動關閉。 5．每題 10 分，滿分 100 分，結束時顯示結算畫面與分數。 先告訴我你要怎麼做，確認後再開始；完成後實際開啟測試，告訴我怎麼試玩。

CHOOSE

三種 Agent 怎麼選

  1. 1
    要處理檔案與文件（Word、Excel、PDF、照片）→ ChatGPT Work
  2. 2
    要寫程式、做網頁、連接 MCP → Codex
  3. 3
    要操作沒有外掛的桌面軟體 → Computer Use
選錯也沒關係：先問 Agent「這件事用哪一種方式最適合？」它會建議你。
