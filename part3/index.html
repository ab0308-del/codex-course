新北市大豐國小　許凱琳老師

觀念

Work、Codex 與 Computer Use

Work 與 Codex 是工作介面，能力有重疊。

Computer Use 是操作畫面的能力，兩種介面都可能使用。

有合適的連接工具時，可以直接處理資料；需要點畫面時，再使用 Computer Use。

準備

開始前的設定

確認 Computer Use 外掛已啟用，依畫面完成授權。

macOS 依提示開啟螢幕錄製與輔助使用；Chrome 依介面連接擴充功能。

Windows 操作時要保持目標視窗可見，避免同時操作同一個 App。

只開放這次需要的 App，登入時由自己操作。

官方設定說明

本次示範

把 PDF 選擇題做成表單

使用操作三下載的「(computer use)複習考卷_地表的靜與動.pdf」。

先確認題目與答案，再設定 Google 表單測驗。

辨識不清楚或沒有答案的題目，先讓老師確認。

提示詞

表單測驗｜直接貼上

請使用 Computer Use，把「【(computer use)複習考卷_地表的靜與動.pdf】」中的選擇題做成 Google 表單測驗。 1. 先讀取 PDF，列出能辨識的選擇題、選項和答案，讓我確認；沒有答案或看不清楚的地方請標示，不要猜。 2. 等我確認題目、答案與每題配分後，用【Chrome】開啟 Google 表單，建立「【地表的靜與動複習測驗】」。 3. 開啟測驗設定，逐題填入題目、選項、正確答案與我確認的配分。 4. 完成後給我編輯網址，讓我自己預覽作答。 需要登入時請停下來讓我操作，不要代填密碼；不要傳送、發布或分享給任何人。
到操作筆記複製完整指令

驗收

表單完成後的檢查

取得編輯網址，自己開啟預覽作答。

核對題數、選項、正確答案、每題配分和總分。

確認沒有自行傳送或分享給學生。

延伸示範

截圖請 AI 幫忙看

請看這張截圖，告訴我目前遇到什麼問題，以及下一步可以怎麼做。先解釋，不要直接更改設定。

截圖先檢查是否包含姓名、帳號、密碼或金鑰。

想讓 AI 實際操作時，再指定 App 與範圍。

加練

電腦效能檢查｜選做

請使用 Computer Use 檢查這台電腦目前 CPU、記憶體和磁碟用量，列出最耗記憶體的前 5 個程式。Windows 請看工作管理員，Mac 請看活動監視器。不要結束任何程式；看完教我下次怎麼自己查。
