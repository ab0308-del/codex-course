外掛程式
擴充 Codex

在你喜愛的工具中協作

新北市大豐國小　·　許凱琳老師

@ 外掛程式

一個面板，接上各種工具

左側「外掛程式」搜尋 → 新增 → 授權。內建官方核心能力：

🖱️ Computer Use

操控你的電腦。

🌐 Chrome / Browser

操控瀏覽器。

🎨 Canva

做設計、簡報。

📊 Spreadsheets / Presentations

表格與簡報處理。

還有 Gmail、GitHub、遊戲開發等大量插件，可在市場搜尋安裝。

PLUGIN ①

Computer Use：操控整台電腦

  • 1
    AI 能看你的螢幕、移動滑鼠、點擊、打字。
  • 2
    操作 Word、PowerPoint 等任何桌面應用程式。
  • 3
    教學雜事：下載考古題、填表單、整理檔案——一句話交辦。

PLUGIN ②

Browser / Chrome：操控瀏覽器

  1. 1
    Browser Use：讓 AI 真正去自動點擊、填表單、翻頁（設定 → 瀏覽器 → 開啟）。
  2. 2
    Chrome 外掛：在 Chrome 裝 Codex 擴充，抓網頁資訊彙整成表格。
  3. 3
    範例：「取得某網站最新 5 篇貼文，彙整成表格。」

PLUGIN ③

Canva 與 GitHub

🎨 Canva

外掛程式接上 Canva → 一句話做海報、簡報、學習單封面、活動視覺。

🚀 GitHub

把做好的網頁推上 GitHub，用 GitHub Pages 免費發佈成網站，別人都能訪問。

Gmail 外掛：請 Codex 幫你「寫一封信並寄出」。

TASK 3

實戰：做個人電子名片網站

  1. 1
    工作模式切換到「適用於程式設計」，回覆更專業。
  2. 2
    建專案夾 namecard，模型選 GPT-5.5、智慧「高」。
  3. 3
    點對話框左下 + → 計畫模式：先規劃再動手。
  4. 4
    給資訊（姓名/職業/簡介/聯絡）+ 要求（生頭像、多風格、響應式、蘋果簡潔風）。
  5. 5
    批註修改：右側內建瀏覽器 → 批註 → 點頁面元素寫意見 → 送出。

謝謝
