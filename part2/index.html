ChatGPT Work Part 2

國小教師 Work
六個實作任務

爬文做教材、雲端取檔、用說的填表、批次獎狀、整理公文、整理照片

新北市大豐國小　·　許凱琳老師

WORKFLOW

不是六個功能，而是一條完整工作流程

口述需求 → 取得資料 → 閱讀與判斷 → 整理與轉換 → 批次產出 → 驗證結果

1．網路爬文製作戶外教育教材

搜尋官方來源，做成學習單與選擇題。

2．從 Google Drive 取得研習素材

確認權限、下載解壓，建立素材盤點表。

3．用說的完成 Word 表單

語音口述活動內容，改寫成正式文字並填入固定欄位。

4．Excel＋Word 批次製作獎狀

讀取學生名單，對應欄位，一次產出每人一張。

5．整理公務處理資料夾

閱讀、分類、重新命名，標示版本與待確認項目。

6．整理旅遊照片

依拍攝時間、GPS 與影像內容分類並改名。

📘 開啟研習操作筆記「提示詞輸入」

BEFORE START

先選好 Work 專案資料夾

  1. 1
    在「文件」建立獨立的研習練習資料夾，不開放整個「下載」或「文件」。
  2. 2
    在 Work 選擇這個資料夾；六個任務都在這裡完成。
  3. 3
    練習素材全部是合成或去識別化資料；正式使用時才換成自己的檔案。
建議順序：任務 1 → 6。任務 2 取得的研習素材包，任務 3～5 都會用到。

TASK 1

網路爬文製作戶外教育教材

示範：淡水紅毛城 × 四年級前導學習

TASK 1 — 提示詞

搜尋 → 判斷來源 → 學習單＋測驗

我要帶四年級學生到「淡水紅毛城」戶外教育，請幫我準備行前教材。 1．上網搜尋資料，優先使用政府、博物館等官方來源，列出每個來源網址。 2．整理適合四年級閱讀的背景重點（約 300 字）。 3．製作一張 A4 學習單：現場觀察任務＋2 題思考題。 4．出 5 題選擇題，附答案與解析。 5．來源不一致或不確定的地方請標示，不要編造。 完成後輸出成 Word。
檢核：點開來源網址確認真的存在；年代、名稱與史實要和官方資料一致。

TASK 2

從 Google Drive 取得研習素材

收到一包雲端資料：先盤點，再建立本機工作環境

TASK 2 — 提示詞

確認權限 → 下載解壓 → 素材盤點表

  1. 1
    素材包連結：研習素材包任務 2 與任務 4 共用
請下載這個 Google Drive 連結中的檔案：（貼上連結） 1．先確認能不能開啟，需要什麼權限；無法開啟就停下來告訴我。 2．下載到目前的專案資料夾並解壓縮。 3．建立素材盤點表：檔名、類型、大小、一句話內容摘要。 不要修改或刪除任何檔案。
檢核：盤點表的檔案數量和資料夾裡實際的數量一致。

TASK 3

用說的完成 Word 表單

活動紀錄、計畫、會議紀錄、成果表：用說的，比打字快

TASK 3 — 提示詞

口述內容 → 正式文字 → 填入固定欄位

按下麥克風，用說的描述：活動名稱、日期、地點、對象與人數、活動流程、學生表現、成果與省思。

請把我剛剛口述的內容整理成正式的公文用語，填入資料夾中的「研習活動成果紀錄表」Word。 1．先用表格列出「欄位 → 建議填入文字」給我確認。 2．我沒提到的資訊留空並標示「待補」，不要自行編造。 3．確認後另存新檔，原始表單保留不動。
檢核：欄位沒有漏填、日期與人數正確、語氣正式、沒有多出我沒說過的內容。

TASK 4

Excel＋Word 批次製作獎狀

一份名單 × 一張範本 → 每位學生一張個人化獎狀

TASK 4 — 提示詞

先對欄位、試產 3 張，再全部產出

請讀取資料夾中的「學生名單」Excel 和「獎狀範本」Word。 1．先檢查欄位對應（班級、座號、姓名、獎項），並列出空白值與重複資料。 2．先產生前 3 張獎狀讓我檢查。 3．我確認後再批次產出全部，存成 Word 與 PDF。 4．最後回報產出張數，以及無法產出的例外名單。

📊 Excel 名單

第一列是欄位名稱，不要合併儲存格。

📁 練習素材

研習素材包 ↗（與任務 2 相同，內含合成名單）

TASK 5

整理公務處理資料夾

檔名混亂、版本不明：不刪除、不覆蓋原始資料

TASK 5 — 提示詞

閱讀 → 分類 → 重新命名 → 對照表

請整理「公務處理」資料夾： 1．先閱讀每份文件，用表格列出：原檔名、內容摘要、建議新檔名、版本判斷。 新檔名格式：日期＿主旨＿學校。 2．提出分類資料夾的規則。 3．整理後的檔案放到「公務處理_整理後」副本，原檔不動。 4．疑似重複或過期的檔案不要刪除，放進「待刪除」由我決定。 5．產出「原檔名 → 新檔名」對照表與「待確認項目」清單。 先給我計畫，等我確認後再執行。
檔案中沒有的日期、主旨或學校不可猜測，一律放入「待確認項目」。

TASK 6

整理旅遊照片

只用「複製」到新資料夾，原始照片保留不動

TASK 6 — 提示詞

盤點、分類、重新命名與整理報告

請整理這個資料夾的旅遊照片： 1．先盤點，不修改；經我確認後，只用「複製」到新資料夾。 2．依 EXIF 拍攝時間、GPS、檔名與影像內容分類。 3．建立分類夾：01_交通 02_海邊 03_景點 04_美食 05_人物 06_夕陽 07_住宿 08_夜景 09_精選封面 10_需要確認。 4．模糊、重複或太暗的放入「10_需要確認」。 5．檔名改成「景點名稱＿日期＿序號＿描述.jpg」。 6．產出整理報告：原始與輸出張數、各夾統計、例外與抽查建議。 請先列出整理流程與風險，等我確認再執行。
隱私提醒：照片的 GPS 會透露位置；分享整理後的照片前，先確認是否要移除定位資訊。

SAFETY · VERIFY

六個任務都用同一個安全節奏

  1. 1
    先盤點：讀取檔案、說明現況與風險，不修改。
  2. 2
    先確認：列出填寫、命名、分類或產出計畫。
  3. 3
    小範圍試做：使用副本，或先處理 3 筆。
  4. 4
    實際驗收：檢查原檔、數量、檔名、內容、格式與例外清單。
個資與著作權：練習用合成資料；網路資料要附來源；學生照片與名單不上傳到不必要的地方。
