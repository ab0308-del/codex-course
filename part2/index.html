Codex Part 2

Computer Use
操控你的電腦

Codex 的招牌絕活

新北市大豐國小　·　許凱琳老師

它在做什麼

Codex 會在背景開虛擬瀏覽器，
像人一樣點、填、操作

而且不影響你當下用電腦——它在背景幫你做事

HANDS-ON

練習：文件資料填報

把作業系統的雜事丟給它

PRACTICE A

上網下載考古題

  1. 1
    建一個資料夾「國中數學歷屆試題」，選進 Codex 專案。
  2. 2
    一句指令：上網找國中數學教育會考最近五年歷屆試題， 下載到這個資料夾，使用你的 Computer Use。
  3. 3
    它會背景開瀏覽器 → 搜尋 → 下拉選單 → 抓連結 → 存檔。

PRACTICE B

處理作業系統的文件資料填報

  • A
    填表單／文件：把資料丟給它，請它填進指定的表格/公文/報名表。
  • B
    整理檔案夾：依類型/日期分類、批次重新命名。
  • C
    操作桌面 App：開特定程式、貼資料、輸出檔案。
  • D
    一次交代多步驟，它會自己想辦法接力完成。

SAFETY

安全與限制

  1. 1
    遇到要登入帳密，它會停下來等你本人輸入。
  2. 2
    敏感網站（網銀、機密帳號）不要讓它代為登入。
  3. 3
    這類 Agent 功能需付費版（要花算力），免費做不到。
Codex 標準速度較慢，但「派下去 → 去忙別的 → 回報」的節奏剛剛好。

謝謝

電腦上的雜事，從此有人代勞
