ChatGPT AI Agent Part 1

環境設置與 Agent 工作法

先設好安全範圍，再把工作交出去

新北市大豐國小　·　許凱琳老師

AI AGENT

回答問題，和實際執行不一樣

💬 ChatGPT

適合問答、整理、寫作與構思。

🧰 ChatGPT 中的 Codex Agent

在授權範圍內讀寫檔案、使用工具並交付成果。

🖱️ Computer Use

操作已授權的桌面應用程式；仍可能受權限與介面變動影響。

🔌 外部連接

透過 Plugin、App Connector 或 MCP 連接 Padlet、Canva、GitHub 等服務。

SETUP ①

下載、登入與建立練習工作區

  1. 1
    到 ChatGPT 官方下載頁安裝 ChatGPT 應用程式，登入自己的帳號。方案、模型與額度會更新，以當天帳號畫面為準
  2. 2
    在「文件」建立獨立練習資料夾，只放假資料與可備份的檔案。
  3. 3
    在 ChatGPT 應用程式中開啟 Codex，再開啟該資料夾；工作區就是 Agent 這次可以工作的主要範圍。

SETUP ②

選擇權限：初學者先守住工作區

預設／依請求

在工作區內執行；超出範圍或遇到敏感操作時再詢問。

代我核准／自動審查

流程較順，但仍要檢查 AI 的自動判斷。

完整存取

自由度與風險最高，不建議初學者直接使用。

推薦自訂

依請求＋工作區寫入；需要查詢或下載時才允許網路。

SETUP ③

個人化、佇列與 Computer Use

  1. 1
    個人化：選「務實」，自訂指令要求繁體中文、先講結論、不確定時明確標示。
  2. 2
    後續訊息：初學者建議使用「佇列」；需要立即改變方向時才使用引導。
  3. 3
    Computer Use：只開啟這堂需要的應用程式；登入、付款、寄送、發布、刪除前人工確認。

WORKFLOW

全課共用：計畫 → 執行 → 驗收

  • 1
    先盤點：只讀取資料、說明現況與風險，不修改。
  • 2
    再計畫：列出步驟、交付成果與驗收方法，等使用者確認。
  • 3
    小範圍試做：先處理 3 筆或建立副本，再完整執行。
  • 4
    實際驗收：打開成果、抽查內容、核對數量與例外，不只看「已完成」。
交辦公式：背景＋目標＋資料＋限制＋交付格式＋驗收標準。

謝謝

環境就緒，會交辦，也會驗收
