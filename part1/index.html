AI AGENT

先看任務要動什麼，再選 Chat、Work 或 Codex

💬 Chat

處理想法與文字：問答、寫作、摘要、翻譯與腦力激盪。

🗂️ ChatGPT Work

完成工作流程：研究、彙整資料，產出文件、試算表、簡報與報告。

🧰 Codex

處理程式專案與本機工具：資料夾、終端機、GitHub、測試與 Padlet MCP。

❓ 一個判斷題

這次真正要動的是想法文字、完整辦公成果，還是程式專案與本機工具？

Work 正逐步開放，功能依方案、平台與工作區設定而異；以授課當天帳號畫面為準。

SETUP ①

下載、登入與建立練習工作區

  1. 1
    到 ChatGPT 官方下載頁安裝 ChatGPT 應用程式，登入自己的帳號。方案、模型與額度會更新，以當天帳號畫面為準
  2. 2
    在「文件」建立獨立練習資料夾，只放假資料與可備份的檔案。
  3. 3
    一般教師文件先選 Work；需要本機資料夾、終端機、GitHub 或 MCP 時，再切換到 Codex。

SETUP ③

個人化、佇列與 Computer Use

  1. 1
    個人化：選「務實」，自訂指令要求繁體中文、先講結論、不確定時明確標示。
  2. 2
    後續訊息：初學者建議使用「佇列」；需要立即改變方向時才使用引導。
  3. 3
    Computer Use：只開啟這堂需要的應用程式；登入、付款、寄送、發布、刪除前人工確認。

WORKFLOW

全課共用：計畫 → 執行 → 驗收

  • 1
    先盤點：只讀取資料、說明現況與風險，不修改。
  • 2
    再計畫：列出步驟、交付成果與驗收方法，等使用者確認。
  • 3
    小範圍試做：先處理 3 筆或建立副本，再完整執行。
  • 4
    實際驗收：打開成果、抽查內容、核對數量與例外，不只看「已完成」。
交辦公式：背景＋目標＋資料＋限制＋交付格式＋驗收標準。

謝謝

環境就緒，會交辦，也會驗收
