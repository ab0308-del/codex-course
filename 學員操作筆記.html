課前準備

登入自己的 ChatGPT 帳號，確認能用的模式與剩餘用量。在電腦建立一個獨立的研習練習資料夾，先放練習素材。 操作一、二接著做；操作三取得素材，再進行操作四、五。操作六完成本機遊戲後，再接 Netlify 分享。 原始素材中的資料夾編號沿用舊版，請依名稱找「批次製作獎狀」與「旅遊照片整理」，以本筆記的操作編號為準。

Chat、Work 與 Codex 怎麼選

Chat：先討論想法、修改文字、釐清需求。 Work：交代要完成的成果，例如搜尋資料、做文件、整理照片與簡報。 Codex：適合查看程式修改、處理專案與執行測試。本研習操作六以 Codex 示範。 Work 和 Codex 能做的事有重疊，也都能用口語交辦；桌面本機任務能否處理資料夾，取決於當天可用工具及授權。Computer Use 是操作畫面的能力，不是第三種產品模式。 參考：https://learn.chatgpt.com/docs/use-chatgpt

個人化設定｜換成自己的介紹

把姓名和任教領域改成自己的內容，再放入個人化設定。

我的名字叫做【姓名】，是一位【國小自然科教師】。
請使用繁體中文回覆，中文使用全形標點符號。
請用清楚、口語的方式說明，不確定的地方直接告訴我。
請減少表情符號，直接切入重點。

操作一：爬文｜搜尋資源，規劃 SEL 課程

選好練習資料夾。貼上後先看課程大綱，確認後才準備第一週。

我要製作【SEL】課程，請建立一個叫做【SEL】的資料夾，這次搜尋到的資料和製作的檔案，都放在這個資料夾裡。

1. 我要設計【4】堂課，分成【4】次上課，每堂【40 分鐘】，對象是【國小四年級學生】，主題是【SEL】。
幫我搜尋網路上可用的教學資源，整理資源介紹、來源和網址，存成 Word 格式，檔名為「網路資源」。
再幫我草擬課程大綱，內容要有每堂課的主題、學習目標和活動安排，存成 Word 格式，檔名為「【SEL】課程大綱」。

2. 請以臺灣國小的教學情境來規劃，也幫我想想還需要哪些教學資料，先提出建議，跟我討論。做到這裡先停下來，等我確認課程大綱。

3. 等我確認後，再準備第一週上課會用到的教案、學習單和材料清單，用 Word 格式存入「第一週」資料夾。PPT 先不要做，我們再另外討論。

完成後看看：打開 Word，看看活動是否適合四年級、時間安排是否可行，並點開資源網址核對。

操作二：生圖｜延續操作一，製作繪本式簡報

等第一週課程確認後，在同一個對話接著貼。子代理功能依當天工具而定，沒有時請 AI 說明可用的分工方式。

現在我們來把【第一週的 SEL 課程】做成【12】頁的繪本式簡報，給【國小四年級學生】上課使用。

每一頁都用全版繪本插圖來設計，使用 imagegen 工具生圖，整份簡報的人物和畫風要一致。圖片裡不要放文字，文字另外放在投影片上，讓我之後可以編輯。

請建立三個 subagent（子代理）分工，每個負責 4 頁。開始前先統一故事內容、角色造型和畫風，再分工製作。

最後合併成一份 PPT，存入前面的【SEL】資料夾，檔名為「【SEL第一週繪本簡報】」。

完成後看看：確認共 12 頁、角色與故事連貫；點選投影片上的文字，測試能否直接修改。

操作三：AI 助理｜從 Google Drive 取得研習素材

先選好專案資料夾。這一步取得的素材會用於操作四、五和延伸示範。

請幫我下載這個 Google Drive 資料夾裡的研習素材：
https://drive.google.com/drive/folders/1B7XGOsAgMnHDs9dcXMlUc6bNgDRKpiUH?usp=drive_link

1. 在目前的專案資料夾裡，建立「【研習素材】」資料夾，把下載的檔案放進去；如果有壓縮檔，請解壓縮，並保留原始壓縮檔。
2. 幫我整理一份「素材盤點表」，列出檔名、檔案類型、大小，以及一句話的內容摘要，存成 Excel。
3. 不要修改或刪除原始素材；如果遇到同名檔案，請另外保留，不要直接覆蓋。
4. 最後告訴我下載了哪些檔案，有沒有無法下載、解壓縮或讀取的檔案。無法讀取的內容請註明，不要猜測。

完成後看看：對照素材盤點表與實際檔案，查看有沒有下載失敗或無法讀取的項目。

操作四：不同檔案的連結｜Excel＋Word 批次製作獎狀

找到學生名單 Excel 和獎狀範本 Word，換成實際檔名。

請讀取資料夾中的「【學生名單】」Excel 和「【獎狀範本】」Word，依照名單製作獎狀，保留範本原本的版面和格式。

1. 先檢查班級、座號、姓名、獎項是否能對應，列出缺少的資料和可能重複的名單。有問題的資料先不要自行補填或刪除。
2. 用資料完整的前【3】位學生製作獎狀，存成 Word 和 PDF，讓我檢查。做到這裡先停下來，等我確認。
3. 我確認後，再批次製作全部獎狀，存成 Word 和 PDF，放進「【獎狀成品】」資料夾。
4. 最後告訴我完成幾張獎狀，並列出無法製作的名單與原因。

完成後看看：先抽查三張的姓名、獎項和版面，再確認是否批次產出。

操作五：閱讀照片｜整理旅遊照片

選取素材裡的旅遊照片資料夾，先看盤點與分類建議，再決定是否執行。

請幫我整理「【旅遊照片】」資料夾裡的照片。

1. 先盤點照片，告訴我打算怎麼分類，以及有哪些需要注意的地方。先不要更動檔案，等我確認後再整理。
2. 分類時，請參考照片的拍攝時間、GPS 位置、檔名和畫面內容。沒有拍攝資訊或無法確定地點的，不要自行猜測。
3. 我確認後，只用「複製」的方式，把照片放進新的「【旅遊照片整理】」資料夾，保留所有原始檔案。
4. 新資料夾內分成：
01_交通、02_海邊、03_景點、04_美食、05_人物、06_夕陽、07_住宿、08_夜景、09_精選封面、10_需要確認。
每張照片先選一個最適合的分類，適合當封面的可以另外複製一份到「09_精選封面」。
5. 模糊、疑似重複、太暗或無法確定分類的照片，放進「10_需要確認」，不要刪除。
6. 複製後的照片改名為「景點名稱＿日期＿序號＿描述」，保留原本的副檔名。無法確認的地點或日期，請標示「地點待確認」或「日期不明」。
7. 最後做一份整理報告，告訴我原本有幾張、整理後有幾張、各資料夾的張數，以及哪些照片需要我確認。封面額外複製的張數請另外列出。

請先回報盤點結果、整理方式和注意事項，等我確認後再執行複製與改名。

完成後看看：查看原始照片仍在；抽查分類、日期、檔名與照片內容，另外核對封面的複製張數。

操作六：做網頁｜成語填空小遊戲

先講解 Work 與 Codex 的差別，再以 Codex 示範製作與測試。玩法可依研習當天調整。

請在這個資料夾製作一個適合【國小四年級學生】玩的成語填空網頁遊戲。

1. 開始時有啟動畫面，顯示遊戲說明和「開始遊戲」按鈕。
2. 準備適合這個年級的四字成語題庫，每次隨機抽【10】題，同一回合不要重複。每題隨機隱藏一個字，讓學生從【4】個不同的候選字中選出正確答案，確保只有一個正確選項。
3. 每題限時【15】秒，用一條會逐漸減少的「時間血條」顯示；另外用不同顏色的「答題進度條」，顯示目前完成幾題，兩者要標示清楚。
4. 答對時顯示慶祝動畫，再自動進入下一題；答錯或時間到時，顯示正確答案，停留【2】秒後自動進入下一題。選完答案後，不要讓學生重複作答。
5. 每題答對得【10】分，答錯或時間到得 0 分，滿分【100】分。結束時顯示分數、答對題數，以及「再玩一次」按鈕。
6. 畫面使用繁體中文，字要清楚，按鈕要方便點選，電腦和手機都能玩。

先用簡單的話告訴我，你打算怎麼設計畫面和遊戲流程，等我確認後再開始製作。
完成後，請實際開啟，測試答對、答錯、時間到和重新開始是否正常，告訴我測試結果，以及怎麼開啟試玩。先在本機試玩，發布上網我們再另外討論。

完成後看看：自己試答對、答錯、逾時及重新開始，核對分數與兩條進度顯示。

操作六補充｜360 環景教材生成器

開啟 360 環景教材生成器（本機副本）

除了成語遊戲，也可以看看另一種教學網頁：輸入主題與參考資料，規劃 360 環景場景，加入知識點、思考題和場景切換。 可以生成圖片、換成自己的 360 照片，調整標示點，預覽後匯出教材網站與專案檔。 補充檔案：https://drive.google.com/file/d/1hwXBe7Zg2KYdAjO0cn5eBBt5n2cVQdBE/view?usp=drivesdk 請先下載 HTML，再用瀏覽器開啟。生成功能需要自己的 OpenAI API Key，會使用 API 額度；共用電腦不要勾選記住金鑰。 這是操作六的延伸範例，不必在研習中另做一個完整任務。

Computer Use｜讓 AI 操作電腦或瀏覽器

適合需要看畫面、點按鈕、輸入內容的任務。先在外掛程式中確認 Computer Use 已啟用，依系統提示授權；macOS 可能需要螢幕錄製與輔助使用權限，操作 Chrome 則依介面連接瀏覽器擴充功能。 這次使用素材中的「(computer use)複習考卷_地表的靜與動.pdf」，不再引用操作一沒有產生的紅毛城試題。 參考：https://learn.chatgpt.com/docs/computer-use

請使用 Computer Use，把「【(computer use)複習考卷_地表的靜與動.pdf】」中的選擇題做成 Google 表單測驗。

1. 先讀取 PDF，列出能辨識的選擇題、選項和答案，讓我確認；沒有答案或看不清楚的地方請標示，不要猜。
2. 等我確認題目、答案與每題配分後，用【Chrome】開啟 Google 表單，建立「【地表的靜與動複習測驗】」。
3. 開啟測驗設定，逐題填入題目、選項、正確答案與我確認的配分。
4. 完成後給我編輯網址，讓我自己預覽作答。

需要登入時請停下來讓我操作，不要代填密碼；不要傳送、發布或分享給任何人。

自己預覽作答，核對題數、選項、答案與總分。
